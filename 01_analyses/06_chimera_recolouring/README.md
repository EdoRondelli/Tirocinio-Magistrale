# CHIMERA X VISUALISATION OF RECUR AND CONTACT
On the basis of the re-indexed protein structures (all belonging to 1 subinit now, so we can map global positions)
Using the master tables (4 column recur y/n/NA + contact) we generated .cxc files which contained the colouring indications for each structure.
The idea is we want to highlight the difference between the recur+contact regions and the recur+no contact regions. To do this the whole structure was coloured grey, and then the 
recur_yes+contact subunits were highlighted bright red, while the recur_no+contact subunits in blue. The recur+no_contact regions are shown in light red, as to see the differences both in 
quantity (which is mainly done through the cchi2 tables) and overall distribution.
